# Google Cloud Sentiment Analysis API vs. Perspective API 비교

이 문서는 Google Cloud의 감정 분석 API와 Jigsaw의 Perspective API라는 두 가지 강력한 텍스트 분석 도구를 비교 설명합니다. 두 API 모두 머신러닝을 기반으로 텍스트를 분석하지만, 서로 다른 목적과 활용 사례를 가지고 있습니다. 개발자나 데이터 분석가가 자신의 프로젝트에 적합한 API를 선택하는 데 도움을 주기 위해 작성되었습니다.

---

## 1. Google Cloud Sentiment Analysis API

Google Cloud Natural Language API의 일부로, 텍스트에 담긴 주관적인 의견이나 감정의 **긍정/부정/중립**을 분석하는 데 중점을 둡니다.

* **제공:** Google Cloud
* **주요 목적:**
    * 텍스트의 전반적인 감정적 어조(긍정, 부정, 중립) 파악
    * 고객 피드백, 제품 리뷰 등의 의견 분석
    * 브랜드 평판 및 시장 반응 추적
* **분석 초점:** 감정의 방향성 (Polarity) 및 강도 (Magnitude)
* **주요 출력:**
    * `score`: 텍스트의 전반적인 감정 점수. 범위는 $-1.0$ (명백한 부정)부터 $+1.0$ (명백한 긍정)까지이며, $0$에 가까울수록 중립적입니다.
    * `magnitude`: 텍스트 전체에 나타난 감정의 총량 또는 강도. 범위는 $0$부터 무한대($\infty$)까지이며, 감정 표현의 강도와 텍스트 길이에 영향을 받습니다.
    * 개체(Entity)별 감정 분석: 텍스트 내 특정 인물, 장소, 제품 등에 대한 개별적인 `score`와 `magnitude`를 제공합니다.
* **주요 활용 사례:**
    * 고객 만족도 분석 (리뷰, 설문조사)
    * 소셜 미디어 여론 모니터링
    * 뉴스 기사나 블로그 게시물의 논조 분석

---

## 2. Perspective API

Jigsaw(Google의 자회사)에서 개발한 API로, 온라인 대화(댓글, 메시지 등)가 토론에 미칠 수 있는 **부정적인 영향(유해성, toxicity)**을 평가하는 데 특화되어 있습니다.

* **제공:** Jigsaw (Google)
* **주요 목적:**
    * 온라인 커뮤니티 및 플랫폼에서 유해하거나 공격적인 콘텐츠 식별
    * 콘텐츠 모더레이션(관리) 자동화 또는 지원
    * 건강한 온라인 대화 환경 조성
* **분석 초점:** 잠재적 유해성, 공격성, 모욕, 위협 등 부정적 영향 측정
* **주요 출력:**
    * 다양한 **유해 속성(Attribute)** 에 대한 가능성 점수. 범위는 $0$부터 $1$까지이며, $1$에 가까울수록 해당 속성을 가질 가능성이 높습니다.
    * **주요 분석 속성 (예시):**
        * `TOXICITY`: 전반적인 유해성 (무례함, 불쾌감 유발 등)
        * `SEVERE_TOXICITY`: 심각한 수준의 유해성
        * `IDENTITY_ATTACK`: 특정 정체성 그룹에 대한 공격
        * `INSULT`: 모욕적인 언어
        * `PROFANITY`: 저속하거나 외설적인 언어
        * `THREAT`: 신체적 위협
* **주요 활용 사례:**
    * 온라인 포럼, 뉴스 사이트, 소셜 미디어의 댓글 필터링 및 자동 관리
    * 온라인 게임 채팅 모니터링
    * 사용자가 자신의 댓글이 타인에게 미칠 영향을 확인하도록 돕는 도구

---

## 3. 핵심 비교 요약

| 특징           | Google Cloud Sentiment Analysis API                     | Perspective API                                      |
| -------------- | ------------------------------------------------------- | ---------------------------------------------------- |
| **주요 목적** | 텍스트의 **감정/의견** 분석 (긍정, 부정, 중립)          | 텍스트의 **유해성/공격성** 분석 (Toxicity, Insult 등) |
| **분석 대상** | 감정적 톤, 주관적 평가                                  | 대화에 미치는 잠재적 부정적 영향, 유해 발언           |
| **핵심 지표** | `score` (방향성), `magnitude` (강도)                    | 유해 속성별 `score` (유해 가능성)                      |
| **활용 분야** | 비즈니스 인텔리전스, 고객 이해, 시장 조사                 | 온라인 커뮤니티 관리, 콘텐츠 모더레이션, 안전          |
| **제공 주체** | Google Cloud                                          | Jigsaw (Google)                                    |

---

## 4. 사용 방법 및 API 접근

두 API 모두 **REST API** 형태로 제공되며, HTTP 요청을 통해 텍스트를 전송하고 분석 결과를 JSON 형식으로 반환받는 방식으로 작동합니다.

* 사용자는 각 API의 공식 문서를 참조하여 API 키 발급, 인증 설정, 요청/응답 형식 등을 확인해야 합니다.
* 다양한 프로그래밍 언어(Python, Java, Node.js 등)에서 라이브러리 또는 직접적인 HTTP 클라이언트를 통해 API를 호출할 수 있습니다.

---

## 5. 결론: 어떤 API를 선택해야 할까?

* **고객의 리뷰나 소셜 미디어 반응에서 긍정/부정 의견을 파악하고 싶다면?**
    * ➡️ **Google Cloud Sentiment Analysis API** 를 사용하세요.
* **온라인 커뮤니티에서 악성 댓글, 모욕, 위협 등을 감지하고 관리하고 싶다면?**
    * ➡️ **Perspective API** 를 사용하세요.

두 API는 상호 보완적일 수도 있지만, 근본적인 목적이 다릅니다. 프로젝트의 목표와 분석하려는 텍스트 데이터의 특성을 명확히 파악하여 가장 적합한 도구를 선택하는 것이 중요합니다.
